MP4 转 VAP 使用说明

  1. 上传 MP4，选择普通视频或绿 / 蓝幕视频。
  2. 选择匹配的去背景方式，先检查透明预览和 Alpha 黑白图。AI 人像只适用于人像，黑白底方式可能误删相近颜色。
  3. 设置尺寸、Alpha 分辨率和目标体积，再开始转换。0.5 / 1.0 表示 Alpha 平面分辨率，不是整体透明度。
  4. 下载 MP4，旧版网页播放器可配合 vapc.json 使用。成品是否适配具体 iOS / Android SDK，仍需目标设备实测。

参数说明

VAP MP4 拼接存储 RGB 与黑白 Alpha；请在本页“透明播放”或 VAP SDK 中查看合成效果。

拖动画面中的四条辅助线，或输入百分比。上、下边缘平滑过渡到透明，中间画面保留；辅助线不写入成品。

遮罩调整实时生效，预览与导出使用当前参数；若已生成成品，修改后需重新转换。

同步羽化会把渐隐写入 RGB 与 Alpha；接入要求直通 RGB 的 SDK 时请选择标准 Alpha。

输出比例锁定

透明边缘宽高各减半，RGB 保持完整尺寸；不是 50% 透明度。

成品严格控制在 3 MB 以内，优先保留输出尺寸、帧率与透明效果，按实际体积自动调整码率；无法达标时不提供超标文件。

本站移动端推荐默认 60%（相对原片约 -4.4 dB），预览与导出同时生效；100% 保持原音量，0% 无声。这是音频增益预设，不是 LUFS 自动响度归一化；实际响度受原片、播放器与设备音量影响，交付前请在目标手机中试听。

默认 H.264 兼容编码；原音量 AAC 直接保留，调整音量时在本机重新编码声音。

视频与声音仅在本机处理，不上传至服务器。
