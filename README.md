# Spreadfun room studio

A browser-based room background generator. Images are processed locally on the user's device.

## Features

- Upload or drag in multiple background images.
- Preview backgrounds with the built-in room UI overlay.
- Export clean-background WebP images at 720 × 1560 and 300 × 480.
- Limit the 720 × 1560 export to 120 KB.
- Adjust the crop and download individual images or one ZIP archive.
- English by default, with a Chinese language switch.

## Run locally

Open `index.html` in a browser. The default UI and logo are embedded; no build, installation, or external libraries are required.

## Publish with GitHub Pages

1. Push this directory to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, then **main** and **/ (root)**.
4. Save and wait for GitHub Pages to publish the site.

GitHub Free supports Pages for public repositories. No server or paid service is required for this static tool.

## Update

Replace `index.html` with the latest `分享包/Room BG Studio.html` from the local project and push the change. GitHub Pages will publish the updated page.
