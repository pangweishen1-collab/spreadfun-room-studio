# Fun Toolkit

当前发布版本 **1.5.0**。VAP 工具支持实时上下透明遮罩与本机导出；`vap-inspect.html` 可打开成品并按内嵌 Alpha 透明播放，普通视频播放器只显示 RGB 与灰度 Alpha 的拼接画面。完整更新见 [CHANGELOG.md](CHANGELOG.md)。

专为乐趣运营打造的素材处理工作台，包含聚合首页、五个生产工具、资源库与共享统计页。图片在浏览器中处理，正式站由 Cloudflare Pages 提供静态资源，API Worker + D1 保存现有工具统计与需求；本地可用 Python + SQLite 预览服务。

- 房间背景工具：批量图片上传、合成预览、每图每尺寸独立裁切、720 × 1560 / 300 × 480 WebP 与 ZIP 下载。
- 头像框预览图生产工具：读取本地 SVGA、循环动态预览、播放/暂停、时间轴、上一帧/下一帧、帧号输入和透明 WebP 单帧导出。
- Banner 生产工具：顶部复用资源库项目组件，提供 Hapi Ludo、Hapi、Yari、4Fun。Hapi Ludo 输出 772 × 200 房间 Banner 与 684 × 240 游戏 Banner（内部 645 × 201，保留外框）；Hapi / Yari 输出 772 × 200，4Fun 输出 680 × 200。按项目居中裁切，使用无损 WebP，支持单独下载与 ZIP。
- 礼物&座驾预览图生产工具：上传 PNG、JPG、WebP，调整构图并导出正方形 WebP；支持场景羽化、透明素材、黑底主体与边缘精修、光效恢复、擦除与恢复、历史记录、旋转和安全区。

### VAP 头像与文字资源（本地开发，尚未发布）

最多添加 6 项头像或文字，支持标签、圆形／方形头像、裁剪／完整显示、字号与颜色、位置尺寸、出现时间和不透明度。直接拖动画面中的资源，或用方向键微调（Shift 为 10 px），参数同步更新，边框不写入成品。原生 VAP 自动读取 `src/frame/mFrame`；移动已有资源位只增加位置偏移，保留原动画与遮挡遮罩。

选中资源后直接拉角缩放，默认保持比例，Shift 自由拉伸；文字字号与框同步变化。小资源只显示右下角手柄，避免点击区域重叠，手柄支持方向键。预览顶部提供修改／替换、居中、复制、删除和撤销／重做；双击文字原位输入，Enter 保存、Esc 取消。精细参数收起后仍可编辑；从列表选择资源会回到预览，未显示的资源定位至有效画面。拖动前自动暂停，保留当前动画帧。30 步资源历史在当前页面内保留，头像 URL 随历史引用回收；更换源文件会重置历史。原生资源缩放与复制继续保留动画和遮罩，预览、动态输出和固定合成使用相同尺寸。

“按标签替换”导出原生 Vapx，MP4 保留标签和资源遮罩；默认头像位于完整 ZIP 的 `resources/`，同时提供 `resources.json`、`vapc.json` 与接入说明。播放时可替换头像与文字，无需重新编码。“固定合成”将当前内容写入 RGB 和 Alpha，单个 MP4 即保留内容。动态资源强制使用预乘 RGB，原生源按官方黑底预乘关系恢复后合成。ZIP 预算包括默认图片、外置配置与封装。

成品验收页支持重新绑定本地头像与文字。格式依据 [Tencent VAP 文档](https://github.com/Tencent/vap/blob/master/Introduction.md) 与 [Web SDK](https://github.com/Tencent/vap/blob/master/web/README.md)。浏览器通过不代表 iOS／Android SDK 真机已认证。素材仍在本机处理，统计仅记录成功生成与下载次数。随 1.5.0 一同发布。

### VAP 转换工具

支持 MP4 视频与图片序列帧两种输入，全部在本机处理。序列帧可多选 PNG／WebP／JPG 或上传一个 ZIP，按文件名自然数字排序（frame_2 在 frame_10 前）；ZIP 自动忽略 macOS 隐藏文件和非图片说明，检查中央目录、逐块限制实际解压量与同尺寸帧。总量上限 200 MiB、7200 帧及所选帧率下的 120 秒，图片最长边 4096；首次只解码首帧、逐帧编码时短暂解码并立即释放，不缓存整个动画的 RGBA。序列帧原生 Alpha 直接写进 VAP，默认预乘模式使用 Canvas 快速打包，避免先转 MP4 和逐帧 CPU 像素往返；标准直通 RGB 或固定资源合成按需使用像素路径。序列 FPS 决定播放时长（帧数／FPS）；修改 FPS 会暂停并保留当前帧。支持预览、拖动时间轴、原始／透明／Alpha 检查及原有头像文字资源。

提供 1／2／3 MB 快捷档与 0.1–3 MB 自定义上限，默认 3 MB、超清优先；编码、重试、MP4 与 ZIP 的最终检查都以当前成品上限为准，分辨率、帧率和透明效果不会为达标而自动降低。5 秒是实际机器、源尺寸与帧数相关的优化目标；短片基准与实际报告分开记录，长片或复杂素材及低体积预算无法保证固定耗时和无损画质。

导航位于资源库左侧，直接入口 `#vap-tools`。普通 MP4 默认保留画面颜色并叠加上下透明渐变，无需额外确认；也可选择黑底、白底、AI 人像或用户遮罩；彩色纯色幕布使用色键并可调边缘与去幕色溢色。Alpha 0.5／1.0 指透明度平面尺寸，RGB 仍保持完整输出尺寸。默认 720×1560、Alpha 0.5、24 FPS、H.264、保留 AAC 声音与 3 MB 硬上限，页面默认“超清优先”（在体积预算内保留更多细节），保留高清／均衡／体积优先可选；上传不覆盖输出尺寸，提供720×1560、750×1624和原片尺寸快捷项，按所选比例联动宽高，上下透明渐变默认启用并展开（顶部 0–15%、底部 85–100%），上传后自动进入透明效果并显示四条可拖动辅助线，调整实时生效，预览与导出使用当前参数；四条边界按百分比随替换视频保留，并在本机保存最近一次有效的启用状态及位置，刷新后重新上传仍沿用；无效输入不覆盖已保存参数，存储不可用时继续保留同页参数；支持透明／Alpha 预览、原版腾讯网页播放器成品预览以及 MP4、vapc.json、ZIP 下载。

界面将自动识别的输入类型与处理方式并排：在本机抽取 12%、50%、85% 三个时间点的缩小帧，检查边缘幕色一致性和多帧共识，识别普通视频及红、橙、黄、绿、青、蓝、紫等彩色纯色幕布；不确定或识别失败时保留普通视频，不自动去背景。识别结果与新素材同时提交，取消或替换失败保留原素材和结果。自动模式将多帧采样的真实 RGB 幕色同时传给预览与编码器，避免首帧黑色片头重新猜成错误幕色；名称只负责显示，黄／青／紫等双高通道及非标准色值使用同一套 RGB 透明度估计、前景颜色恢复与去溢色。手动选色后不再沿用原自动幕色，回到自动重新使用该素材的采样值。灰白黑、中性色及不确定的场景保持普通视频，黑白底仍使用对应的显式处理方式；与幕色完全相同的主体细节和真实半透明度无法仅凭单张合成颜色唯一恢复，需检查 Alpha 或使用原始遮罩。去背景方式与幕色使用原生下拉，标题在框内左侧、当前值在右侧。未上传时仅显示满宽上传区；上传成功后显示当前／输出双预览，预览模式位于当前画面下方；两侧背景在预览框下方统一调整，只保留透明／黑／白。上下渐变四个边界在桌面端单行排列，遮罩无需确认即可生效，修改会使旧成品失效，不适用的边缘精修隐藏。参数解释集中在“使用说明”，右侧保留参数、必要状态及下载操作。 折叠标题将状态与16px SVG箭头固定为同轴操作组，间距8px，长标题只在标题槽换行；复用规则见设计规范1.4.3的“折叠标题：状态与箭头对齐”。

视频不上传到服务端。Mediabunny 本地解码和封装，WebCodecs 本地编码；默认使用移动端推荐音量 60%（约 -4.4 dB），提供原声 100% 快捷项并保留 0–200% 手动调节；100% 音量时原 AAC 音频直接保留，其他音频仅在浏览器可以真实转码 AAC 时处理，否则明确提示。音量预设属于本站增益建议，不是 LUFS 自动响度归一化；实际播放需在目标设备试听。视频音量同时作用于左侧预览和实际导出；0% 或关闭保留声音时不输出音轨，非 100% 真实调整 PCM 后重新编码 AAC。右侧成品默认静音播放，避免左右同时出声。 网页成品预览显式使用与直通RGB/Alpha一致的非预乘WebGL上下文，防止半透明渐变合成发白；官方SDK文件与导出颜色通道保持原样。AI 为人像范围的 MediaPipe VIDEO 模型，不宣称能通用分割所有礼物、动物或复杂特效。黑白底模式有颜色歧义，需通过预览检查主体暗部／亮部；保留背景模式本身不抠图，可叠加上下透明渐变。

同一效果预览框内始终按 1:1 显示当前效果和输出效果，手机端上下排列；上传前、待转换和生成中分别显示真实空态或处理状态。两侧共享透明（棋盘格）／黑／白背景，切换不影响导出文件；未上传时保持与 Banner 一致的浅蓝渐变。成品由原版腾讯网页播放器读取，首帧暂停，可通过“透明播放”查看；VAP MP4 是 RGB 与黑白 Alpha 拼接资源，QuickTime 等普通视频播放器会同时显示两部分，不会替用户合成透明效果。下载回执和帮助会明确此用途；播放器加载失败仍保留可下载文件。符合条件的 H.264 保留背景模式复用静态 Alpha 平面，并直接绘制 RGB，避免逐帧 JavaScript 像素往返；保留原编码色彩范围，其他处理方式或不确定的源覆盖范围继续走原处理器。性能报告区分实际处理、Canvas 提交和编码时间，Canvas 提交时间不代表 GPU 执行时间。

限制为 200 MiB、120 秒、源边最长 4096、输出边最长 2048、最多 60 FPS，并受设备实际编解码能力限制。成品上限为十进制 3 MB（3,000,000 字节），可设更小上限；所有预设均受硬限制，先按时长、音轨和封装开销规划码率，最多四次有界编码，逐次校验真实成品字节数。分辨率、帧率、透明遮罩和音量不因压缩自动降级；为 ZIP/config 预留空间，MP4/ZIP 下载均检查 3 MB。无法达标时返回体积错误并保留原素材/已有有效成品，不提供超标下载。相同体积下长视频或复杂画面的细节仍受码率预算限制。网页播放器通过不等于 Android／iOS 真机已认证。本版本发布验收与已知边界见 CHANGELOG 1.5.0；手机 SDK 仍需目标设备实测。依赖原版许可证与固定来源保留在各自 vendor 目录。

### 黑底抠图与实时预览（1.2.4）

均匀深色底图使用 Lucida 1024 透明度估计，再在原尺寸恢复前景色与透明度。主体暗部由学习到的主体透明度保护，光效和粒子保留原图的颜色信号；清除与背景匹配的外部残留后，再缩小并无损编码 WebP。其他底色继续使用既有 AI 路径。

模型分块最多三路并发下载，逐块与整包校验，保留已验证缓存供失败重试；连续五分钟没有实际进展才终止，正常慢网加载不会被总时限中断。模型仅量化矩阵乘法权重为 8 位，激活、采样和计算保留 FP32；下载约 423MB，分成 21 个校验分块，在本机缓存。优先使用 WebGPU；无可用 GPU 时由独立 ONNX Runtime 1.30 WASM 运行。满足跨源隔离和共享内存时最多使用 4 线程。模型与运行时声明位于 `assets/lucida/`、`vendor/ort-lucida/`。图片留在浏览器内处理。

本轮狮子样例经过真正客户端、Worker、缩放、前景恢复和 200×200 WebP 导出验证。22 项固定检查与白／蓝／深灰背景人工复查通过；真实界面首轮与替换图片后的导出像素一致。这是样例验证，不代表单张合成图可以恢复唯一的原始透明图层。

本机完整客户端模型就绪后的新图片处理约 9.2 秒，编辑页约 15.3 秒；包含本地组件和模型加载的首轮约 13.7–16 秒，首次网络下载另受网速影响。2 秒目标尚未达到。图捕获和半精度计算未采用：前者整模更慢，后者在该样例重新产生棕色边缘。此前 1.2.2 的较快数据属于旧质量路径，不能作为本版本结果。

同图完成结果仍仅保留一份内存缓存，还原后再抠图可直接复用；换图会重新推理。结果数组独立复制，保护笔刷与历史记录。缓存命中不计作新图处理速度。

上传成功后，“效果预览”框内按 5:5 展示编辑画布和礼物栏实时效果；空态只显示上传区，手机端上下排列。礼物栏不再有独立白卡、标题或切换按钮。200／240／400／500 快捷尺寸保持 1:1，并沿用到后续替换图片；自定义尺寸、历史操作和导出保留。

17 个回归套件覆盖现有工具、加载与失败重试、GPU 读回、浮点合成、尺寸与实时预览。当前界面也完成桌面与 320px 空态／上传后状态检查。详细质量与时间记录保存在本地交付目录，不进入站点。

## 预览

在本目录执行：

```sh
python3 server.py --host 127.0.0.1 --port 8765
```

或双击 `start-preview.command`，然后用浏览器打开：

- `http://127.0.0.1:8765/index.html#room-backgrounds`
- `http://127.0.0.1:8765/index.html#avatar-frames`
- `http://127.0.0.1:8765/index.html#banners`
- `http://127.0.0.1:8765/index.html#gift-previews`
- `http://127.0.0.1:8765/index.html#resources`
- `http://127.0.0.1:8765/index.html#home`（不带地址片段时也进入首页）
- `http://127.0.0.1:8765/index.html#statistics`

需要 Python 3.9 或更新版本。请使用 `server.py` 启动；普通静态服务器仍可使用图片工具，但无法提供共享统计或接收需求，页面会显示服务不可用。

`Room BG Studio.html` 是旧书签的跳转入口。最新源码入口为 `index.html`，需要同时保留各工具的 CSS/JS、`assets/`、`vendor/` 和 `design-system/`，不能只复制一个 HTML。发布时使用 `npm run build:pages` 生成完整目录。

## 统计与需求

- 覆盖范围：房间背景、头像框、Banner、礼物图、VAP、资源库六个工具的生成与下载统一记录到首页累计和 `#statistics`。新增工具从接入后开始累计，不补算未上报的旧使用记录。
- 生成次数：每个成功输出的文件计 1 次。房间背景一次输出两个尺寸，计 2 次；Banner 按项目实际生成的文件数计次（Hapi Ludo 2 次，其他项目 1 次）；头像框和礼物图导出计 1 次；资源库每次新编码并提交的图片计 1 次；VAP 每次成功转换的 MP4 计 1 次，JSON 配置和 ZIP 打包不额外计生成。缓存文件再次下载不重新计生成。房间背景删除旧图或添加新图时，不重复累计未变化的旧文件；成功重新裁切一个尺寸计 1 次。
- 下载次数：每次有效发起单文件或 ZIP 下载计 1 次，不按 ZIP 内文件数累加，也不表示浏览器已完成保存。预览、播放、切换语言与背景不计数。
- 全站统计由同一个服务接收并持久化，支持多个客户端共享与服务重启后保留。不会把旧的浏览器本机累计冒充全站历史，也不计算用户人数。统计服务不可用时显示“—”和重试提示。
- 仅上报随机事件编号、工具、行为与数量，不上传用户素材、文件名或 IP。重试使用相同编号，后端幂等；匿名上报仍可能因持续断网或页面在排队期间关闭而漏计。
- 首页“提出工具需求”可提交标题、任务说明和选填联系方式。提交成功返回真实编号，失败保留输入；需求没有公开列表。作者双击 `view-requests.command`，或运行 `python3 server.py --list-requests` 查看。

macOS 默认数据文件为 `~/Library/Application Support/Fun Toolkit/toolkit.sqlite3`，位于网站目录之外，不进入 ZIP。可用 `FUN_TOOLKIT_DATA_DIR` 设置私有数据目录，或使用 `python3 server.py --db /absolute/private/path/toolkit.sqlite3` 指定文件；服务器拒绝将数据库放在网站目录内。

接口为 `GET /api/stats`、`POST /api/events` 与 `POST /api/requests`。正式站已由 Cloudflare Worker + D1 提供跨用户累计；单独复制静态页面不包含这项服务。旧使用次数无法追溯。

## 头像框工具用法

1. 选择顶部“头像框”，点击上传，或将一个 `.svga` 文件拖入页面。
2. 读取后默认停在第 1 帧，可直接导出；点击“播放”才开始动画。拖动时间轴、点击上一帧/下一帧，或输入帧号并按 Enter，停在需要的帧。替换文件后同样回到第 1 帧暂停。
3. 默认输出 240 × 240。宽、高任意一边都可修改，另一边等比例联动，固定为 1:1。支持 16–2048 的整数像素。
4. 点击“导出 WebP”，压缩并保存当前选中的静态帧。导出时自动暂停，保留所设尺寸与素材本身的透明区域。棋盘格只用于预览，不写入图片。

非正方形素材会等比放入正方形透明画布，避免拉伸。导出文件名包含源文件名、帧号和输出尺寸。离开工具、后台标签页或预览离开视口时暂停播放。

支持经过验证的 SVGA 2.0 与 ZIP 格式 1.x；音轨不播放。文件需小于 50 MB。读取失败会提示，并保留上一次有效素材；不会上传用户的文件。

## Banner 工具用法

点击标题旁的灰色“使用说明”按钮，可查看 GPT 生图建议：在提示词中写明宽高比为 3.3:1。弹窗提供可直接参考的文字和关闭按钮，支持中英文及手机布局。房间背景的灰色“案例图片”按钮也统一放在标题旁。

选择顶部 Banner 后先选择项目，右侧立即显示对应尺寸。点击上传或把一张 PNG、JPG、WebP 拖入页面，即可预览并下载。Hapi Ludo 保留房间和游戏两个尺寸，Hapi / Yari 为 772 × 200，4Fun 为 680 × 200；上传后切换项目直接复用已解码的原图重新生成，失败保留原项目和可用文件。输入限制 30 MB、4000 万像素；默认居中裁切填满，不拉伸。游戏外框来自本次提供的 `11 2.zip`，名义图片区域位于 x=19.5、y=18，大小 645 × 201，保留原有圆角和 3px 外框。

导出固定尺寸且仅编码一次，保留游戏图透明边缘。替换失败保留上次有效结果；切换工具或语言不清空结果。

Banner 使用本地 WebAssembly 编码器进行无损 WebP 压缩，保留裁切后画面的像素与 Alpha，不设置体积上限或降低画质。文件通常比旧版 0.92 有损编码更大。首次上传时按需加载本地编码器，加载失败会提示重试，不会改用有损编码。房间背景工具和头像框工具继续沿用各自已有导出规则。

原图宽度小于 772px 或高度小于 201px 时，会提示放大可能变模糊；建议使用至少 772 × 201px 的原图。无损编码不会恢复低分辨率图片中缺失的细节。

游戏 Banner 默认使用黑色预览底色，可通过“黑色 / 透明”切换为透明棋盘格。此设置只改变预览容器，不写入画布或导出文件，WebP 始终保留原有透明区域。

### 商店图标预设

资源库提供 iOS App Store（1024 × 1024、RGB PNG，无 Alpha）和 Google Play（512 × 512、RGBA PNG、sRGB、最大 1024 KB）预设，固定平台尺寸与 PNG；切回自定义可恢复原有尺寸和格式。按用途选择后逐个平台下载。iOS 透明区域填白，两种文件均保持完整正方形，不增加圆角或外部阴影。

这是平面商店图标输出，不生成 Android Adaptive 前景/背景或 Apple Icon Composer 工程。小于 1024px 的原图导出 iOS 时会放大并提示。平台预设使用原生 CompressionStream 无损 PNG 编码，缺少该能力会明确提示，不降级生成错误通道文件。

规范来源：[Apple Xcode](https://developer.apple.com/documentation/xcode/configuring-your-app-icon)、[Apple App icons](https://developer.apple.com/design/human-interface-guidelines/app-icons)、[Google Play](https://developer.android.com/distribute/google-play/resources/icon-design-specifications)。核验日期：2026-10-24。随网站 1.1.0 纳入发布。

### 直角与自定义圆角

资源库默认以 0% 直角预览和导出。自定义尺寸提供 0–50% 圆角滑杆与整数输入框，圆角按输出边长等比计算；50% 为圆形。PNG/WebP 裁切区域外透明，JPG 填白，预览同步显示。参数变化使旧下载失效，切换项目/语言保留设置；商店预设强制输出直角，切回自定义恢复原圆角。

### 输出速度复验（本地 · 2026-10-24）

本地预览：http://127.0.0.1:8792/#room-backgrounds 。以下为本机性能测量，相关修改随网站 1.1.0 纳入发布。

- Banner 保留完全无损、exact alpha 与 method 1，将无损编码搜索力度降至 0；此参数只影响搜索耗时和文件体积，不降低像素质量。同素材三次生成中位数 146.7 → 84.2ms；实际下载的两张 WebP 解码 RGBA 与原版完全相同，样例文件增加约 3.8%–4.7%。
