02 / LOADING & PROGRESS

不知道进度，就不编百分比

读取、生成、打包用真实阶段名。视觉反馈统一，任务状态由业务驱动。

形式何时用参数 / 行为
按钮 Spinner单一动作，进度未知。16×16 px、2 px 线宽、800 ms 线性旋转；配“正在生成…”，保宽、防重。
区域 Spinner局部读取、解码、请求中。常规 24×24 px，大预览区 32×32 px；16 / 24 用 2 px 线宽，32 用 2.5 px。只占相关区域。
确定进度可以获取实际完成量。原生 progress 或有名称的 progressbar；显示真实值 / “已完成 2 / 5”，未知时不推算倒计时。
不确定进度总量 / 耗时未知。Spinner + 阶段文字；自定义 progressbar 省略 aria-valuenow。不按时间自动涨到 90%。
Skeleton等待结构已知的远程图文 / 列表。1600 ms 低对比浅蓝脉冲；结构对应内容。不叠加大 Spinner；局部更新优先保留旧内容。

立即响应，视觉加载可延迟 150 ms

点击后立即改变业务状态、设置 busy 并防重。Spinner / Skeleton 可在等待超过 150 ms 后挂载；提前完成就直接显示结果。延迟由业务控制，基础样式不创建计时器，也不强制最短等待。

真实进度、错误、取消和完成不额外延迟。只在已实现时显示取消；离屏 / 后台暂停视觉循环，实际任务是否暂停由业务决定，不悄悄取消。

03 / PLACEHOLDERS

预留位置，不假装结果

未上传、等待加载、图片损坏和透明背景各有含义，不能用同一张灰图糊过去。

类型视觉与尺寸结束条件
文本 Skeleton普通条 12 px、标题条 16 px；行容器 18 / 24 px、行间 8 px。固定宽度组合，如 72% / 100% / 52%，不随机。成功替换成内容；无内容切空态；失败显示真实错误。
图片 Placeholderplaceholder-image.svg 为 160×120，头像另用 120×120 方形图。预留目标比例与圆角；浅色底、居中轮廓图形，声明尺寸或 aspect-ratio。实际 load / 解码成功后换真图；不作为可下载结果。
图片损坏原位显示静态图标 + “图片暂时无法显示”，保留真实文件信息。仅实际失败后出现；有能力才给重试；不继续脉冲或无限重试。
透明棋盘表达真实图片的透明区域。属于预览背景，不是占位，不进入透明文件导出。

Skeleton 形状隐藏于辅助技术，由区域名称与一条状态文字说明。用户尚未上传素材时用空态，不用 Skeleton 假装后台生成。

04 / ENTER & EXIT

轻轻出现，干净退场

普通内容用短位移；弹窗保留已有轻弹性与玻璃背景。业务反馈不等待动画。

场景统一参数边界
出现180 ms；opacity 0→1、Y 6→0 px；cubic-bezier(.16,1,.3,1)。标题辅助、说明、卡片、新结果；只动 opacity / transform。
退场120 ms；opacity 1→0、Y 0→3 px。结束后隐藏 / 移除；先安置焦点并停止交互，透明按钮不可点、不可 Tab。
错峰相邻 ≤40 ms，最多前三项；延迟总预算 ≤120 ms。同屏少量卡片 / 装饰；长列表不逐项排队。
即时反馈状态、错误、进度和可用性立即更新。不等动画后才显示错误、接收点击或提供真实下载。
快速反复切换新的出现取消旧退场与完成回调。旧回调不能隐藏新内容，任务状态仍以业务为准。

弹窗继续使用已有 260 ms 轻弹性、7 px 玻璃背景。内容不因反复滚入视口而每次重播；无脚本 / 减动仍可阅读，不把整页正文初始设透明等待 JS。

05 / DECORATIVE PARALLAX

一点层次，不改变操作

用于页头、品牌插画和空态的独立装饰层。工具素材和操作坐标保持稳定。

类型位移上限停止与降级
PointerX / Y 各 ≤6 px；仅 hover:hover + pointer:fine。离开回原位；触屏、粗指针、≤540 px、减动静态。
ScrollY ≤12 px；深度 0–1，整体幅度受上限约束。离屏 / 后台停止；可见后按当前位置恢复。
执行动画帧合并输入，只对装饰层 transform。不逐事件读写布局；无任务不空转；销毁时释放监听与观察。

不会动的部分，同样属于规范

不对工具 Canvas、裁切框、图像坐标、输入框、按钮文字、时间轴或导出层做视差。装饰层 pointer-events:none、aria-hidden="true"，不承担唯一信息，不改素材像素或命中坐标。

06 / ACCESSIBILITY & FALLBACKS

少动，也要说清楚发生了什么

  • 减少动画：出入场立即完成，视差归零，旋转与脉冲停用，Skeleton 静态；保留阶段文字与真实进度。
  • 离屏 / 后台暂停视觉循环。业务状态和结果照常更新；动画暂停不等于取消生成。
  • 任务区有名称，真实处理期间 aria-busy=true；用一条不受 busy 延迟的 role=status / aria-live=polite 消息，按阶段更新，不逐帧播报。
  • 只在必须立即处理的阻断错误使用 role=alert；同一消息不在多个 live region 重复，整张卡片不作播报区。
  • 进度有名称与真实值；图形、颜色和旋转不能代替文字。相邻文案完整时空态图 alt 为空。
  • 状态切换不抢焦点；关闭 / 删除含焦点区域前移至存续入口，退出区及时不可交互。弹窗沿用原有焦点圈定与返回。
  • 标题、说明、恢复动作、进度及 ARIA 一起中英切换。320 px、长英文、200% 缩放与键盘操作仍可用。
07 / IMPLEMENTATION & ACCEPTANCE

复制规则，也检查真实行为

下列参数属于新增组件与可复用示例标准。现有三个工具保留实际业务流程，不代表已经统一接入全部能力；基础 PDF 仍为 v1.2。

给开发 / Agent 的短需求

按 Fun Toolkit 反馈规范实现 [模块]：从六类选择真实状态并使用配套 SVG，常规 120×90 / 手机 96×72；每区一个突出动作。未知进度用 16 / 24 / 32 px、800 ms Spinner，有真实完成量才显示进度。业务立即 busy 防重，视觉加载可延迟 150 ms，不延迟完成与错误。Skeleton 固定结构、1600 ms 轻脉冲，图片区分待载入 / 损坏 / 透明棋盘。入场 180 ms / 6 px，退场 120 ms / 3 px；错峰 ≤40 ms、最多三项、总延迟 ≤120 ms。装饰视差 Pointer ≤6 px、Scroll ≤12 px；离屏 / 后台停，手机 / 减动静态。Canvas、裁切坐标与导出层不变换。补齐中英、状态播报与焦点；未接能力明确标为示例。

验收清单

  1. 无内容、加载、失败区分清楚；原因、恢复动作与保存承诺都真实。
  2. 图形等比、无图中文字，布局稳定；失败保留上一份有效素材。
  3. 快任务不闪占位，慢任务持续有文字；无假进度、假取消、假下载。
  4. 图片成功 / 损坏 / 缺失可验证；透明棋盘不进入导出。
  5. 快速入退场不留透明点击区，不延迟业务反馈；长列表不排队。
  6. 移动、粗指针和减动无视差；离屏 / 后台停视觉循环；销毁释放资源。
  7. 320 / 390 / 768 / 1440 px、长英文、200% 缩放、键盘均可用；完成后 busy 复位。
  8. 真实生成前后尺寸、像素、透明度不受装饰影响；规范演示不写生产统计。
