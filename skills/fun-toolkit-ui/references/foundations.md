# 视觉、控件与表单

本包的 `assets/tool-page-starter/design-tokens.json` 与 CSS 是资源规范 1.4.2 的可执行值。修改现有产品先复用其共享组件，再按本表补齐，不把 `.ft-ui` 全局覆盖到未审查的旧页面。

## 颜色和层级

| 用途 | 值 / 规则 |
| --- | --- |
| 品牌 | 蓝 #136BFF、深蓝 #0B45D9、黄 #FFC928；品牌黑 #111111 只用于文字标识 |
| 主动作 | #0071E3，Hover #0062CC，按下 #0055B3，白字 |
| 替换素材 | #21834B，Hover #196B3C，按下 #155C34，白字 |
| 页面 / 卡片 | #F5F5F7 / #FFFFFF；分隔 #E8E8ED；浅蓝预览 #EAF3FF |
| 文字 | 标题 #202A3B、正文 #1D1D1F、辅助 #626C7C、弱提示 #6E7785 |
| 状态 | 成功 #237957、警告 #8A4B00、错误 #B42318，配浅色底与文字/图标 |
| 不可用 | 底 #EDF0F4、字 #647083、边 #D8DCE2；附近解释不可用原因 |

普通次按钮使用白/浅蓝底与蓝字；帮助按钮灰色轻底。区域内只突出当前主动作。删除用危险色并按实际可恢复性设计确认，不把绿色替换按钮误当危险动作。选中不能只靠颜色。

## 排版与尺度

系统无衬线字体（含 PingFang SC / Microsoft YaHei）；正文 14/22px、400；控件 14/20px、500；说明 12/18px、400；区块标题 16/24px、650；页标题 26/32px、700，手机 22/28px。导航 16/22px、固定600字重，选中用蓝色、无下划线；Hover仅颜色和柔和光晕，不改变字重、宽度或文字位置，点击不带动相邻项。语言和联系作者保持小字号常规字重。

间距用 4、8、12、16、24、32、48、64px。桌面容器含留白最多 1440px，外留白 42px（平板24、手机16）；卡片24px内边距，手机16；工作区间距16。圆角：输入10、内部12、预览16、卡片22（手机18）、弹窗20px。不要为两行说明造新卡片。

900px及以下工作区单列；540px及以下手机规则。最小320px不横向溢出，长英文、文件名和结果列表能换行/省略并保留可访问名称。主要按钮44px高；紧凑控件可32/36px，但手机命中区至少44px。数值、文本输入在手机为16px，避免缩放跳动。不要把页面关键动作固定到遮挡内容的位置。

## 控件状态

每种实际使用的控件覆盖默认、Hover、按下、键盘焦点、选中/已填、禁用、只读、加载、错误。正常Hover保持蓝色调。原生按钮/链接语义优先；导航用链接，操作用按钮。

输入框 1px 边 #8B95A5，Hover #626C7C；鼠标焦点1px蓝边与2px极淡光晕。键盘焦点2px外环、偏移2px，不叠加成粗双环。错误边优先，保留文字说明；只读仍可读可复制，与禁用不同。使用 `focus-modality.js` 保留键盘/指针区别和 forced-colors 可见焦点。

主按钮可加 `ft-motion-sheen`：480ms单次低强度扫光；禁用/处理中不扫，触屏无残留Hover，减少动态效果时静态。不让按钮文字/宽度因加载跳动。

## 下拉选择框

实现直接复用 `assets/tool-page-starter/select.css`，DOM 示例见随包 `index.html` 的 `.ft-select`：选择器与装饰 SVG 放在同一个包装层，样式文件在页面控件样式之后引入。

下拉选择使用真实 `<select>`，保留方向键、键盘输入检索、系统选项面板与手机原生选择器；不要为统一箭头外观自制菜单。所有页面和模板复用同一套选择框样式，不能只设置 `padding-right`，仍把箭头的位置交给浏览器内建外观。

- 常规模式关闭原生箭头外观（`appearance: none`，兼容时含 `-webkit-appearance`），使用包装层内的装饰箭头。箭头尺寸 **16×16px**，右边缘距控件右边框 **16px**，相对控件可见高度垂直居中；内容右内边距 **44px**，长选中项不能进入箭头区域。
- 箭头不响应指针事件、不可聚焦，并从辅助技术隐藏，点击箭头区域仍打开真实选择框。页面 label、帮助文字和错误与真实 `<select>` 关联；长选中项可省略，完整选项仍在系统面板中可读。
- 高度、边框、圆角与输入框统一。默认箭头为辅助文字色；Hover 和焦点用蓝调。禁用时控件与箭头使用不可用色，不能继续交互；错误边优先，保留错误说明与 `aria-invalid`；键盘焦点沿用2px外环、偏移2px，不能在箭头上另画焦点。
- 手机选择框字号 **16px**、命中高度至少 **44px**；收窄宽度或切换中英文时仍保持16px右侧留白，不挤压或遮挡箭头。
- `forced-colors: active` 下隐藏装饰箭头并恢复 `appearance: auto`，交还系统原生箭头、边框与可见焦点；确保只有一个箭头。此时系统高对比可读性优先于常规模式的16px定位。

## 表单模式

- 所有字段有常驻 label，单位、默认值、范围、必填/选填清楚；placeholder只举例。帮助文字用aria-describedby关联。
- 数值用number或合适inputmode，执行范围与整数/小数校验；宽高锁定时修改一边同步另一边。用户输入中的过渡值与提交值分开处理，修正必须可见，不暗改成意外值。
- 文本支持真实maxlength；多行内容有合理高度和长度提示。仅在实际搜索为空时显示无结果，清除后保留焦点与恢复列表。
- 单选、复选、开关、下拉和分段选择根据语义选用，选中状态可访问；不可用选项解释原因。二选一开关不伪装成导航。
- 文件选择同时支持可点击入口；拖放是补充，不只支持鼠标拖入。校验扩展名/MIME与实际解码、尺寸和大小；错误指向文件，不清空无关字段。
- 提交时一次展示可定位的错误，保留已填内容；适合时在字段离焦后验证，不逐键报错。处理中防重复提交，成功展示实际结果或回执；请求失败保留草稿并提供真实可用的恢复动作。
- 结果受参数影响时标为待重新生成或禁用旧下载；下载文案为“已发起下载”，不能保证用户系统已保存。

## 弹窗、辅助层与结果

帮助弹窗使用原生dialog与一致的轻弹性/玻璃遮罩，有标题、关闭按钮与Esc关闭，打开进入焦点、关闭返回触发控件；长内容自身滚动，手机不超屏。提示气泡、菜单、折叠区只在业务需要时添加，并保证键盘可达。关键错误不只靠短暂Toast。

批量列表有稳定任务标识、文件名、规格、体积和单项结果；部分失败不冒充全部成功，重试只处理实际失败项。选择/全选的可用范围明确；ZIP只打包可用结果，空列表不可下载。裁切确认前保留草稿、取消恢复；透明棋盘、黑色预览和操作控件不能进入导出像素。

统计区区分加载、真实0、已有旧值更新与读取失败；不可用显示“—”并给刷新，不能把失败当0。所有数值来自真实结果，演示页面不调用生产统计。
