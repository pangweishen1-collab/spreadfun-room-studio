# 现有网站的接入边界

`assets/production-adapter/` 是 **2026-10-23三工具历史适配层快照**，仅识别 roomTool/avatarTool/bannerTool、当时的状态字段、图片节点及 `design-system/assets/feedback/` 路径。保留快照用于理解旧接入，不表示它已覆盖当前六个工具；本轮不改写这些历史适配文件。

**新独立页面从Starter接入基础库，不直接导入历史生产适配层。** Starter使用自己的DOM和状态控制器，适配层不会自动注册新工具；硬拷会找不到节点或重置不相关状态。修改原站时保留原业务方法和脚本顺序，把新状态准确映射到UI层，不把业务进度放入纯动效助手。

## 当前共享统计

客户端与API目前登记六个ID：`room`（房间背景）、`avatar`（头像框）、`banner`（Banner）、`gift`（礼物图）、`resources`（资源库）、`vap`（VAP工具）。显示标题与hash路由可以不同，事件使用上述稳定ID。各工具从接入后开始累计，未记录的历史产出无法补算；统计不是用户人数。

成功生成的业务输出文件与有效发起的下载动作分开统计：每个新的有效输出计1，一次生成两个规格计2；读取、粘贴、预览、背景／语言切换、失败不计生成。复用同一结果再次下载不重复计生成；VAP配置JSON及对既有结果打包ZIP不额外计生成。单文件、JSON或ZIP每次有效发起下载计1，不代表系统已保存完成。

原站route/hash、全站翻译和统计在toolkit.js、index.html、hub.js及API worker服务中分别接入。未来新增标识仍需同步导航、首页、直接访问路由、翻译、客户端允许列表与API服务端登记；已有六ID不意味着有任意新工具的自动注册API。独立模板不发送正式统计；本包不带生产账户、数据库、密钥或任意事件发送脚本。

## 原站视觉与反馈

原站仍有legacy样式；本包tokens是新组件的统一参考，不代表全部旧选择器已经改为tokens。局部接入使用作用域并回归相邻工具，避免同名全局CSS改变其他页面。

一般内容入场180ms / Y6→0、退场120ms / Y0→3；媒体/工具切换适配为160ms纯opacity，避免Canvas命中坐标变化。两者用途不同，不为统一数字强行移动媒体。
