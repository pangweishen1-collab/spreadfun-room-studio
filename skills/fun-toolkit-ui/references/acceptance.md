# 工具页面交付验收

按本次实际功能选择必要检查，记录观察与未测范围，不以此清单制造未要求的功能。页面模板、业务功能、真实设备和团队效果分别说明。

1. 检查 320 / 375 / 768 / 1280px；中文与长英文无横向溢出；布局单列时结果和下载可滚动到达，操作区≥44px，手机输入16px。
2. 页头、标题/帮助、工作卡、输出卡和页脚使用相同变量与组件；主动作蓝色、替换绿色、普通Hover蓝调、选中短细下划线，焦点不叠粗线。
3. 无素材使用对应空态，不能假装加载；8张反馈图完整等比。声明预览尺寸/比例，加载不造成明显跳动。
4. 有效文件真正读取与预览；非法类型、损坏文件、超出真实限制给清楚错误，保留输入或前一份有效结果的行为可验证。
5. 真实任务驱动loading/processing；忙时防重、aria-busy=true，完成/失败/取消正确收尾为false；未知进度不假涨，快速任务不强制等待。
6. Spinner800ms、Skeleton1600ms；适用时离屏/后台暂停。减少动态效果时继续显示状态文字与进度；若不能切换系统设置，说明只检查了代码与媒体查询规则。
7. 弹窗可开关、Esc退出、焦点返回；玻璃模糊有不支持时的底色降级。切换中不留下透明可点击层、不阻塞下载。
8. 快速替换文件、修改参数、切换语言/预览背景/视口不会提交过期结果；取消和旧结果有效性按需求验证。
9. 内容淡入不变换Canvas/裁切坐标；视差只作用装饰，手机/粗指针/减动静态。连续播放/每帧更新不重播入场。
10. 表单有label、说明和可定位错误；只读/禁用明确；Tab顺序合理，200%缩放关键动作可达。状态播报不逐帧重复。
11. 真正生成与下载文件，解码检查格式、尺寸、透明通道和画面内容；ZIP检查CRC及成员一致性。不能只看按钮文字成功。
12. 压缩策略满足业务画质/体积要求；Banner原站采用无损WebP，其他工具不可未经需求直接套低质量或固定体积。
13. 若接共享统计，成功文件和有效下载动作分别核对；失败、语言、导航、预览背景切换不计数；测试事件是否计入正式累计须说明。
14. 检查控制台与资源404；记录版本、环境、真实产物和截图。浏览器视口不是实体手机；独立Agent试做不是同事真人审批。
15. 使用下拉选择框时，核对共享样式与真实 `<select>`：常规模式箭头16×16px、右边缘距右边框16px、垂直居中，内容右内边距44px；不能仅改内边距却仍依赖浏览器内建箭头。分别检查320 / 375px及窄卡片、中文与长英文选中项，文字不盖箭头，右侧留白不贴边。手机字号16px、命中高度≥44px，点击箭头区域与键盘操作都能打开或切换系统选项；禁用、错误和键盘焦点沿用输入框规范。`forced-colors` 下装饰箭头隐藏、原生箭头恢复且不重复，系统边框与焦点可见；未实际测试系统面板或高对比模式时如实记录。

新工具流程必须从上传一直到实际下载走通。对纯UI改动复用同一版本有效业务测试，只补受影响的状态与布局。没有发布授权只交预览；用户已明确授权发布则验证通过后完成发布及线上资源核验。
