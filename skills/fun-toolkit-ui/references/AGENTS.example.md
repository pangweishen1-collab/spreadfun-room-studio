# Fun Toolkit 项目规则片段

将以下规则合并到项目已有AGENTS.md中，按项目实际情况调整；不要覆盖原文件。

- 新建或修改Fun Toolkit工具页面时，使用仓库中的 `$fun-toolkit-ui` 并先读取相关规范。
- 优先复用既有tokens、全站壳、控件、空状态和动效。保留用户选择的技术栈和真实业务，不为套模板重写项目。
- 新工具应明确输入、参数默认值、输出、失败恢复和统计时点；演示状态不能冒充真实生成或下载。
- 交付前检查中英文、移动布局、相关状态和真实文件输出；把实测与未测范围分开说明。
- 用户要求发布时按项目既有部署流程执行；调用Skill本身不授权生产写入或发布。
