# 团队接入与更新

## 首次使用

先新建名为 `fun-toolkit-ui` 的目录，再将ZIP内容解压到其中，让SKILL.md直接位于该目录下（不要多嵌套一层）。里面有scripts、references和assets。保留相对路径。在线规范用于看示例，本包离线即可搭建；网页下载动作不会自动安装Skill。

Codex可把完整目录放入目标项目 `.agents/skills/fun-toolkit-ui/`。由Agent读取SKILL.md并按该客户端的技能发现/重载方式确认可见；显式用 `$fun-toolkit-ui` 调用。其他兼容SKILL.md的客户端按自身文档添加整个目录；本包不保证未经验证的客户端自动安装兼容。

如果只想试做，可以把解压目录路径和“读取这个SKILL.md并按它执行”交给有文件/终端权限的Agent，无需改全局配置。Python3.9+仅用于随包的复制/校验脚本；无Python可完整复制模板。页面资源不依赖Node、包管理器或远程字体。启动本地预览可在生成页面目录运行 `python3 -m http.server 8080 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8080/`。

## 更新方式

团队保存一个来源仓库和固定版本。Skill1.0.2绑定资源规范1.4.2；升级时先比较说明与资源，再整体替换Skill目录并检查包，不零散复制新CSS到旧JS。已有业务页面由维护者按差异接入，不自动覆盖、强推或重写项目。版本号与归档SHA用于识别同一份交付；旧PDF只是历史参考，不是当前模板的唯一依据。
